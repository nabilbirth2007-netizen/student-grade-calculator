# Student Grade Calculator Using C

## About the Project

The Student Grade Calculator is a simple C program that accepts marks for five subjects, calculates the total marks and percentage, and determines the student's grade.

## Features

- Accepts marks for five subjects
- Calculates total marks
- Calculates percentage
- Determines grade
- Displays the result

## Grade System

| Percentage | Grade |
|---|---|
| 90–100 | A+ |
| 80–89 | A |
| 70–79 | B |
| 60–69 | C |
| 50–59 | D |
| Below 50 | F |

## Technologies Used

- C Programming Language
- stdio.h

## Concepts Used

- Variables
- Data types
- printf()
- scanf()
- Arithmetic operators
- if-else statements

## How to Run

1. Open main.c in a C compiler.
2. Compile the program.
3. Run the program.
4. Enter marks for five subjects.
5. The program displays total, percentage, and grade.
